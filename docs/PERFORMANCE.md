# Performance

## 优化内容

- `--jobs` 默认使用 `available_parallelism`，最多 8 个 worker；`--jobs 1` 保留串行路径。
- 嵌套深度和圈复杂度合并为一次函数 AST 遍历。
- 行号使用枚举计算，避免逐行重复扫描前缀。
- import binding 使用边界检查代替逐项正则编译。
- 字符串、类型和 JSX 范围使用排序索引；嵌套范围按实际覆盖关系判断，避免漏掉外层范围。

测试同时确认没有通过减少规则、跳过文件或降低 coverage 来提速。
